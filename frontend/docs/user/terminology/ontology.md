The ontology is the dictionary of **sources**, **sounds** and **labels** included in APLOSE (based
on [MetadataX](https://github.com/PAM-Standardization/metadatax)).

The **sources** and **sounds** are defined by an English name, a French name and a code name. They are defined in a hierarchy.
Each user can choose if he is rather like them displayed in English, French or code name.

The **label** is the join of a source and an optional sound. It is used for annotation.
